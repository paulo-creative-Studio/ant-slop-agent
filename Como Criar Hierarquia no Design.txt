Já aconteceu de você olhar um post e não saber por onde começar a leitura, e você olhar e falar, por onde eu começo? Então, se isso já aconteceu com você, o que acontece é que falta hierarquia visual, que é uma das bases do design. Você falou, o que é hierarquia? Hierarquia é dispor os elementos de forma que você olhe e saiba por onde começar e aonde termina a leitura daquele post, daquele cartaz, daquele design. É como se você estivesse dizendo, primeiro você olha aqui, depois aqui e finaliza aqui.

Então, você pensa, ah, tá bom, entendi, falta hierarquia. E agora? Agora eu vou te ensinar como usar a hierarquia para melhorar os seus projetos. Seja num post, num cartaz, numa apresentação, e esses simples pontos vão fazer diferença no momento que você fizer o seu projeto e for apresentar.

Como criar hierarquia? Simples. Vou te dar algumas opções para você trazer a hierarquia para os seus projetos. Primeiro, tamanho.

O que for maior, sim, é o que vai chamar a atenção. Então, quando você quer que um elemento chame mais a atenção, você vai aumentar ele, deixar ele maior do que os demais elementos. Outra forma é o contraste.

Você pode criar contraste entre o fundo e o texto e os demais elementos. Você precisa usar cores que, quando você olhar, elas descolam uma da outra. Não tem como você criar esse contraste se você joga um amarelo, um fundo amarelo, e depois você coloca uma fonte branca.

Não vai girar contraste. Contraste, para ficar muito mais claro, talvez, na sua cabeça, é como se fosse preto sobre branco. É como se fosse uma cor mais escura com uma cor mais clara.

Então, se o background é mais escuro, se o BG é um BG mais escuro, você vai usar fontes e elementos para chamar a atenção. Então, para descolar desse fundo, eles precisam ser mais claros, senão não vai haver esse descolar do fundo. Outra forma é o alinhamento.

Proximidade e distanciamento criam grupos no momento da leitura. Se o mesmo elemento faz parte daquela informação que você quer passar, você, então, faz com que você agrupe os elementos próximos um do outro, para mostrar que aquelas informações, que aquela parte do seu design, eles estão agrupados e estão passando uma informação juntos, para que as pessoas entendam qual é o grupinho que cada parte faz parte, entendeu? Além do seu elemento no seu design. Você precisa deixar claro o que é título, o que é subtítulo, o que é texto e o que é uma chamada para a ação.

Isso precisa estar claro no seu design. Não pode ser algo que a pessoa tem que imaginar ou que ela tem que ficar olhando diversas e diversas vezes até entender o que é cada coisa. Outra possibilidade de você criar essa hierarquia é com ritmo e repetição.

Por que eu tenho que usar ritmo e repetição? Para manter a coerência naquilo que você está fazendo. Por exemplo, se você faz um carrossel para o Instagram, você tem que usar essa repetição para que as pessoas entendam que cada slide daquele carrossel faz parte do mesmo carrossel, para não ficar algo desconectado. Se você olhar, não.

Mas tem alguma coisa errada aqui. Essa repetição vai fazer com que os elementos pareçam fazer parte daquele mesmo grupo, daquela mesma informação, daquela mesma mixagem. Para você falar, tá bom, como eu posso fazer isso? Repita as cores, as fontes que você usou no seu texto.

Ou seja, quando alguém olhar, precisa entender que tudo ali faz parte de um todo, que não é algo desconectado. Se você não usa essa repetição, você acaba criando uma desconexão entre os elementos. E para você não esquecer isso, quando você for finalizar o seu projeto, se pergunte antes de finalizar, por mais simples que ele seja, ainda que seja um post só com slide.
